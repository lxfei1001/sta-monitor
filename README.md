# 领星好仓库监控助手（sta-monitor）

一个 Chrome 浏览器扩展（MV3），帮助亚马逊卖家在领星 ERP 创建 STA（Send to Amazon）后，**自动监控亚马逊分配的入库仓库（物流中心编码）**——当分配结果中的「好仓库」达到设定数量时，通过钉钉机器人即时提醒，否则自动重试，全程无需人工盯守。

> **为什么需要它**：亚马逊 FBA 入库分配的仓库直接影响入仓时效和运费。好仓库（如 ONT8、LGB8、VGT2 等）意味着更快的上架速度。手动反复「重新分配」盯结果非常耗时，本工具把这个过程完全自动化。

## ✨ 核心功能

- **一键监控**：在领星页面手动把 STA 建到「提交装箱」步骤，把任务 ID 粘进侧边栏，剩下的交给插件
- **自动操作**：自动点击「提交装箱并继续」→ 读取「入库配置选项」中全部货件的物流中心编码
- **智能判定**：与 30 个好仓白名单比对（去重），命中 ≥ 阈值（默认 3 个）即达标
- **自动重试**：未达标则等 10 分钟，自动点「上一步」回到装箱步骤重新提交，循环直至达标或达到最大尝试次数（默认 100 次）
- **钉钉提醒**：达标后通过钉钉群机器人推送命中仓库明细（可选，配置 webhook 即启用）
- **常驻侧边栏**：Chrome Side Panel 面板，不随页面跳转消失，实时日志滚动显示
- **智能容错**：登录过期自动等待重登、页面元素模糊匹配、插件刷新后旧页面自动重注入、卡在「下一步」时自动推进

## 🔒 安全红线

> **本插件在任何情况下都不会点击「申报货件并提交配送服务」**——即永远不会真正向亚马逊申报货件。所有操作都停留在 STA 向导的第②步（装箱）内，不产生正式货件，不影响入库限额。

## 🚀 快速开始

1. 打开 Chrome → `chrome://extensions/` → 开启「开发者模式」→「加载已解压的扩展程序」→ 选择 `extension/` 目录
2. 点击工具栏插件图标，打开侧边栏
3. 在领星 ERP 手动创建 STA 至装箱步骤（不要继续往下点），复制页面任务 ID（localTaskId）粘入侧边栏
4. 点「开始监控」——达标后看钉钉/日志通知

详细图文教程见 **[用户使用手册](docs/领星好仓库监控助手-用户使用手册-v0.1.0.docx)**（Word 版，含截图，适合新手）或 `extension/安装说明.md`。

## ⚙️ 配置

| 文件 | 说明 |
|---|---|
| `extension/config.js` | 阈值（默认 3）、轮询间隔（默认 10 分钟）、最大尝试次数（默认 100）、领星向导页地址 |
| `config/warehouse_whitelist.json` | 好仓白名单（30 个物流中心编码）+ 判定阈值，改这里无需动代码 |
| `config/dingtalk.json` | 钉钉群机器人 webhook + 加签 secret，填好即启用钉钉提醒 |

