# 领星好仓库监控助手 · Chrome 插件 v0.1

## 安装（一次性）

1. 打开 Chrome，地址栏输入 `chrome://extensions` 回车
2. 打开右上角「**开发者模式**」开关
3. 点左上角「**加载已解压的扩展程序**」
4. 选择本目录：`sta-monitor/extension`
5. 固定到工具栏：点拼图图标 → 把「领星好仓库监控助手」钉住

> 领星需在 Chrome 中**已登录**（你日常用的登录态即可，插件跑在你自己的浏览器里）。

## 使用流程

### 模式一：监控已有 STA（推荐，v0.3.0 主流程）

前提：你在领星手动创建好 STA（完成到商品装箱步骤），拿到 `localTaskId`
（可从 STA 任务列表「编辑」时的网址里看到 `localTaskId=xxxxx`）。

1. 点插件图标打开弹窗
2. 顶部「监控已有 STA」框里粘贴 localTaskId → 点「**开始监控**」
3. 插件自动循环：
   - 打开该 STA 的编辑页 → 点「**提交装箱并继续**」（无此按钮则点「创建」）→ 确认弹窗
   - 等亚马逊返回仓库分配（约 20~60 秒），抓取全部物流中心编码
   - **好仓 ≥3 个**：✅ 系统通知提醒，停止重试
   - **<3 个**：⏳ 记录本次结果，**10 分钟后自动点「上一步」重新提交装箱**，循环直到出好仓
4. 随时可点「停止」；每次尝试的全部仓库都记录在案（弹窗可见最近一次，历史存浏览器本地）

> ⚠️ **铁律：插件永远不会点「申报货件并提交配送服务」**——只读仓库分配，不会真实申报货件。

**注意**：
- 监控运行期间领星标签页保持打开即可，弹窗可以关掉，重试由浏览器闹钟驱动
- 每 10 分钟一次重新提交装箱，会消耗亚马逊的入库配置生成次数，属正常监控成本
- 监控期间若领星登录过期，页面会跳登录页，重新登录后监控自动恢复

### 结果判定（两模式相同）

- ✅ 好仓去重后 **≥3 个**：绿色提示 + 系统通知
- ⚠️ **<3 个**：按模式规则重试或仅记录

## 已知的不确定点（v0.1 需实测调优）

插件是盲写的第一版，领星页面的具体控件结构未实测，以下环节可能需要微调：

1. **店铺下拉框**的控件类型（按 ant-design 组件写的，若领星用别的组件库可能找不到）——找不到时浮动条会让你手动选，不影响跑通
2. **导入商品对话框**：自动填文件用的是标准文件输入框方案，若领星用自定义上传组件可能要走「手动选文件」降级
3. **暂存是否出结果**：若点暂存后 2.5 分钟内没出现入库配置，说明暂存路径不可用，届时告诉我，我们改走「创建后取消」策略
4. **结果文本提取**：编码提取基于白名单匹配 + 通用「3字母+数字」正则，个别非常规编码可能漏抓（结果页原文会完整保留，可人工核对）

**遇到任何一步卡住：点弹窗里「复制结果与调试日志」，把内容发我，我按日志修对应环节。**

## 数据说明

- Excel 文件只在本地流转（弹窗读取 → 原样传给页面自己的上传框），不经过任何第三方
- 运行记录存在浏览器本地（chrome.storage），最近 200 条
